# nvda-hazir-cevap
sık kopyaladığınız metinleri önceden kayıt edin, klavye kısayolları atayın hızlıca yapıştırın

## Kullanım
- `python build.py` ile `hazirCevap.nvda-addon` oluşturun ve NVDA'ya yükleyin (NVDA 2024.1+).
- NVDA+Ctrl+Shift+H: yönetici (ekle, düzenle, sil, yapıştır). Her kayda isteğe bağlı kısayol (örn. `kb:NVDA+control+1`) atanabilir.
- NVDA+Ctrl+Shift+L: listeden seçip yapıştır.
- Kısayolları Girdi Hareketleri iletişim kutusundan da değiştirebilirsiniz. Kayıt sayısı sınırsızdır.
